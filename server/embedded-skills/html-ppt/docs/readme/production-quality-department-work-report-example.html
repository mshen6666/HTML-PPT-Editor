Part 01 · 部门职能

部门职能概述

生产技术质量部是集团公司职能部门，统筹技术管理、质量管理、体系建设、网络安全、信息化建设与档案管理等核心工作。

🛠 技术管理

制定完善技术管理制度，编制技术发展规划；组织标准规范收集更新发布；参与编制国家级、行业级工法和技术标准。

✅ 质量管理与三标体系

项目过程质量监督，三标体系内审外审换证；重大质量事故调查及顾客投诉处理。

🔒 保密与网络安全

建立保密制度并组织实施；涉密人员培训及保密检查；网络安全管理制度，保障信息系统安全。

💻 信息化与档案管理

信息化建设规划，数字化转型；综合信息系统运维；纸电档案制度制定与执行。

📋 生产支持与专家管理

大中型项目技术方案论证与指导；工程回访和技术总结；专家库建设及项目专家团队组建。

📐 项目管控

院管项目策划及大纲审定；内外业检查；内部稽察；设计成果审定与评审；成果出版前检查。

生产技术质量部 · 专题汇报 质量管控

Quality · 质量管控

压实质量管控主体责任

2024年9月集团公司出台《勘测设计产品技术质量提升实施方案》，明确质量管控三大抓手。

① 一把手责任

各生产单位院长（总经理）对本单位勘测设计质量负总责。通过研讨剖析、现场抽查引领质量管理工作。生产技术质量部每季度监督汇总并上报集团公司。

目标：形成自上而下质量管控模式

② 总工程师职责

从管理体系运行、项目质量管理、设计评审等环节落实质量责任制。生产技术质量部定期监督评估履职情况。

目标：压实质量管理职责，守住底线

③ 全员质量文化

生产单位每年开展≥2次管理体系宣讲教育和质量剖析会，形成标准化文本推广应用。通过全员教育培训测试提升质量管理能力。

目标：打造企业质量文化，提高全员意识

生产技术质量部 · 专题汇报 贯标与信息化

Integration · 贯标体系与信息化

深化全过程管理转型与信息安全保障

🔄 动态化管控

将三标体系要求全面融入项目管理系统，实现"备案制"向"全过程管理"转变。

每季度开展变更管理"线上巡查"，将设计变更合规性纳入分院考核。

📜 制度化建设

出台《集团公司设计变更管理办法》，修订《专家管理办法》《勘察设计产品质量和现场服务管理办法》，压实技术管理责任。

🔒 保密与网络安全

  • 建立保密制度并组织实施，涉密人员培训及检查
  • 网络安全管理制度，保障信息系统安全
  • 失泄密途径识别与防范措施

💻 信息化建设

  • 发布《信息化规划（2023-2030）》，启动三化建设
  • 构建全新综合管理平台，数字化纳入技术质量考核
  • 2024年3月 入选国务院国资委数字化转型试点企业

Assessment · 技术质量目标考核

2025年技术质量目标考核办法

按照生产单位不同业务类型和发展实际，分为两类单位考核

📐 技术目标（7项）

  • 技术培训组织与实施
  • 科研项目推进与管理
  • "四新"技术和知识产权
  • 优秀项目申报及获奖
  • 数字化技术推广应用
  • QC小组活动开展
  • 技术资料归档、保密与网络安全

✅ 质量管理目标（6项）

  • 管理体系运行有效性
  • 分包管理规范性
  • 院内质量控制执行
  • 实物质量管理水平
  • 设计变更及现场服务
  • 其他质量管理工作

考核坚持分类施策原则，技术目标 + 质量管理目标双维度驱动，确保全方位提升

生产技术质量部 · 专题汇报 长效管理

Mechanism · 长效管理机制

构建长效管理机制

从人才、考核、协同三个维度建立可持续的质量管理体系

1

人才与专业协同

建立水文水资源、造价经评、机电与金属结构、水土保持、征地移民等5个"配套专业"交流平台，凝聚专业合力。充实内外部专家库，赋予专家质量监督职责。

2

考核与问责机制

将技术质量工作纳入年终考核；对瞒报变更、虚报整改的分院通报批评追责扣分。建立"责任倒查机制"，重大违规变更追溯至分院领导。

3

跨部门协同治理

联合市场经营部、人力资源部等多部门构建统一奖罚制度，避免"制度矛盾、重复奖惩"。形成多方联动、齐抓共管的治理格局。

长效管理机制
三个维度：人才平台建设解决专业能力问题，考核问责解决执行力度问题，跨部门协同解决管理盲区问题。
